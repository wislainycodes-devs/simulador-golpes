# simulador-golpes
Protótipo funcional do Simulador de Golpes - Projeto Integrador III (PI-III).
# Simulador de Segurança Digital — Você Cairia Nessa?

Protótipo funcional desenvolvido para a Entrega 3 (Prototipação) do Projeto Integrador III (PI-III), referente ao 3º período dos cursos de Engenharia de Software e Inteligência Artificial da Faculdade Metropolitana de Anápolis (FAMA).

## Sobre o projeto
O objetivo desta aplicação é conscientizar o público sobre riscos virtuais, engenharia social e fraudes do cotidiano. O simulador apresenta situações práticas estruturadas com base em orientações de segurança oficiais, permitindo que o utilizador teste suas decisões e compreenda os riscos associados de forma educativa.

## Cenários contemplados
O sistema abrange seis situações centrais planejadas pelo grupo:
1. Falso familiar (pedidos de Pix por número desconhecido).
2. Falso banco (alertas de transações suspeitas e links de phishing).
3. Links e anexos desconhecidos (riscos de malwares).
4. Pedidos de código de verificação (proteção de contas e credenciais).
5. Perfis falsos e conteúdos gerados com inteligência artificial.
6. Orientações de reação e conduta pós-golpe.

## Funcionalidades da interface
- Mecânica interativa com opções de resposta dinâmicas.
- Feedback imediato após cada escolha, apresentando explicações, sinais de alerta e canais de ajuda.
- Ferramentas de acessibilidade integradas, como ajuste de tamanho de fonte e modo de alto contraste.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript (ES6+)
